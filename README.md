# TRANSCRIPT

**Governed Execution Infrastructure**

TRANSCRIPT is the governed execution line within XMECK-LAB.

Its first public subsystem is **KAVACH**, the trust / authority / continuity / protection substrate used to model protected software actions.

## Current public state

- **KAVACH 2.0 — Software Reference / Public Engineering Preview:** published under [`KAVACH/`](KAVACH/)
- **KAVACH 1.0 — Historical Engineering Preview:** preserved on `release/kavach-1.x`
- **TRANSCRIPT runtime:** not yet publicly admitted in this repository

KAVACH is published first because its software-reference authority and continuity model has an independently bounded public surface. Publication of KAVACH does not imply that future TRANSCRIPT runtime, XPADI, XAIPT, XLP, KAVACH-OS, hardware-backed providers, or private adapters are public or admitted.

## Repository law

**Public evidence is narrower than private engineering history.**

Only release-admitted public surfaces are projected here. Founder governance, private qualification evidence, future consumer mappings, private adapters and unreleased engineering remain outside this repository.
