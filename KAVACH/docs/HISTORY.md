# KAVACH History

## 1.0 — Trust-Continuity Capability Security

The first public historical engineering line demonstrated a runnable Windows product surface around AIRS, Trust Core, capability authority, K-LOCK, Trust Epoch, Evidence and ProofCheck.

## 2.0 — Continuity-Bound Authority & Protection Substrate

The current software-reference line refines the model around evidence-backed trust appraisal, explicit OPEN/HOLD/REFUSE decisions, bounded authority, continuity revalidation and authenticated evidence.

KAVACH-OS and the R18 provider/SDK repositories remain private engineering lineages and are not public product version numbers.
