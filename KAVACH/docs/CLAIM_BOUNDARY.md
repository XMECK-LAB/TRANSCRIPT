# Claim Boundary

KAVACH 2.0 is published as a **Software Reference / Public Engineering Preview**.

Supported public statements:

- software-reference implementation
- OPEN / HOLD / REFUSE decision semantics
- continuity-bound authority model
- one-use and stale-authority refusal semantics
- recovery invalidation semantics
- authenticated evidence model
- public SDK/reference-client surface

Not admitted by this public release:

- hardware-backed or TPM-backed protection
- TEE or HSM assurance
- independently certified security
- formal verification
- vulnerability-free or production-certified status
- real external consumer enforcement
- future private ecosystem integrations
