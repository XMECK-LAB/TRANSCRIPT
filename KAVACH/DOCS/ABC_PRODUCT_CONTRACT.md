# KAVACH V1 ABC Product Contract

## A — Integration Kit
Stable schemas, SDK/API, reference consumer, capability-envelope schema, security profile, provider contract and adapter boundary. External project code is not embedded.

## B — Public Demonstrator
A bounded real-runtime proof centered on Trust Lab: establish trust, protected operation, controlled trust loss, enforcement, recovery, stale replay refusal, fresh authority, evidence verification.

## C — Authority Console
Full AIRS, Trust Core, Capabilities, K-LOCK, Evidence, Runtime, Integrations, SDK/API and ProofCheck instrumentation. It exposes assurance limitations and provider identity.

All three consume the same KAVACH Runtime/Core.
