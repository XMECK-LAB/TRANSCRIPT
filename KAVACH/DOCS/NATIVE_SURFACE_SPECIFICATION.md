# KAVACH V1 Native Surface Specification

Information architecture: COMMAND → TRUST → PROOF → SYSTEM.

State semantics:
- OPEN = cyan/blue coherent flow.
- HOLD = controlled orange interruption.
- REFUSE = red closed path.

The Trust Core orb is a visualization of authoritative runtime state only. UI state never creates authority.

AIRS uses categorical pipeline semantics rather than decorative security scores. K-LOCK lifecycle motion maps to actual request/appraisal/issue/execute/consume/refuse events. Evidence Inspector exposes receipt identity, sequence, event, epoch, bindings, reason, predecessor, authenticator and verification information. Raw JSON is an advanced engineering view.
