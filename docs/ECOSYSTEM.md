# XMECK Ecosystem Context

## Public hierarchy

```text
XMECK-LAB
└── TRANSCRIPT
    └── KAVACH
```

### XMECK-LAB

Public engineering organization for selected XMECK working-software and engineering lines.

### TRANSCRIPT

**Governed Execution Infrastructure**

TRANSCRIPT is the parent execution-governance line. It provides the public architectural context in which protected execution can be separated from ordinary request/permission handling.

### KAVACH

**Continuity-Bound Authority & Protection Substrate**

KAVACH is the currently published TRANSCRIPT subsystem for:

- evidence-derived trust appraisal;
- explicit `OPEN / HOLD / REFUSE` decisions;
- bounded authority;
- continuity;
- protected execution;
- authenticated evidence.

## Broader XMECK relationship

XMECK includes other product and engineering lines with separate responsibilities.

Their existence does not imply live KAVACH integration.

A relationship becomes an **admitted integration** only when there is a real consumer implementation, frozen contract, qualification evidence, and an explicitly admitted public claim.
