# Security Policy

This repository contains public engineering previews and software-reference implementations.

KAVACH 2.0 is **not** represented as hardware-backed, independently certified, formally verified, vulnerability-free or production-certified security.

Please report suspected security issues privately to the project owner rather than publishing exploit details in a public issue before coordinated review.

## Current assurance boundary

- Software reference
- Non-hardware assurance
- External consumers are not independently admitted by this public release
- Trusted publisher signing is not claimed for the historical KAVACH 1.0 Windows binaries
